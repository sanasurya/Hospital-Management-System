# Hospital Management System
A Java-based Hospital Management System developed using Object-Oriented Programming (OOP) concepts and a Swing GUI.

## Features
OOP Design: Utilizes classes, inheritance, encapsulation, and polymorphism.
Swing GUI: User-friendly interface to manage patients, doctors, and staff.
Role-based Forms: Add records based on the selected role (Patient, Doctor, Staff).
Functionalities: Add records, admit/discharge patients, assign doctors, and calculate bills.
Search System: Search for records by name.
Login System: Secure access to the admin dashboard (Username: admin, Password: admin123).
## How to Run
Compile the java files: javac *.java
Run the main GUI class: java HospitalGUI
